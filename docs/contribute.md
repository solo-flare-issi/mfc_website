# Contribute

This site is maintained on GitHub and community contributions are
welcome. Everything here is version-controlled, so corrections are easy
to make and easy to review.

Repository: [github.com/solo-flare-issi/mfc-website](https://github.com/solo-flare-issi/mfc-website)

## Flag a correction

If something in the catalogue or the narrative pages is wrong, a
mis-recorded window, a missing flare, a wrong coordinator, a broken link,
then please **open a GitHub issue**. Include the page and, if you have it,
the correct value and where it comes from.

Every page has an **edit icon** at the top right that takes you straight
to its source file on GitHub.

## Add a paper to the publications tracker

Open a pull request adding the paper to `docs/publications.md`. Please
include the full citation and a DOI. If the paper is about a specific
event in the catalogue, say which one, so it can also be linked from that
event's detail page.

## Contribute quicklook code

Per-campaign data products. STIX and HRI timeseries, FOV overplots,
orbit plots, JHelioviewer movies, are generated by scripts kept
alongside the catalogue. Pull requests are welcome.

## Add campaign information

The factual content of the catalogue comes from the team's working
spreadsheet, which is maintained by the team. If you have information
about a campaign window, coordinated observations we have missed,
observing notes, a flare that should be recorded, open an issue rather
than editing the generated pages directly, as generated pages are
overwritten on the next build.

## Conventions

- **Narrative pages** (`about.md`, `trigger-campaigns.md`,
  `resources.md`, `publications.md`, `team.md`) are edited directly.
- **Generated pages** (the campaign and flare catalogues and their detail
  pages) are built from the catalogue data and must not be edited by
  hand.
- Prose is British English, one sentence per line where practical, so
  that diffs stay readable.
- Times are UT throughout; dates are ISO format (`YYYY-MM-DD`).
